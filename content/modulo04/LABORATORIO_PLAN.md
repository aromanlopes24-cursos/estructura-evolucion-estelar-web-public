# Laboratorio 04 — Fuentes de energía estelar

## Base del curso

Las clases comparan tres fuentes principales:
- energía química;
- energía gravitacional;
- energía nuclear.

Para una esfera uniforme:
    U_g = -3GM²/(5R)

Usando el virial, la energía radiable en una contracción desde Ri >> R es:
    ΔE ≈ 3GM²/(10R)

y:
    t_KH = ΔE/L

Para el Sol, el material obtiene una escala ~10^7 años.

La estimación química usa energías electrónicas de orden 1–10 eV por átomo y
produce una escala ~10^5 años.

La estimación nuclear adopta:
    eficiencia ≈ 0.007
    masa participante ≈ 0.10 M
y produce una escala ~10^10 años.

## Material complementario

La curva de energía de enlace muestra:
- crecimiento de Eb/A para núcleos ligeros;
- máximo en la región Fe–Ni;
- fusión de ligeros hacia mayor Eb/A como proceso exotérmico.

Para p–p:
    U_C(r) ≈ 1.44 MeV fm / r

El punto de retorno clásico:
    r_c = 1.44 MeV fm / E

El factor de Gamow:
    P_G ≈ exp(-2πη)

La ventana de Gamow surge del producto entre el factor térmico y la
penetración por túnel. Para T≈1.55×10^7 K, el material complementario da
E0≈6 keV.
